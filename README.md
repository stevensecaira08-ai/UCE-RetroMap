# 🏛️ UCE RetroMap: Central Explorer

Un videojuego web interactivo de exploración en 2D que recrea el campus de la **Universidad Central del Ecuador (UCE)** utilizando una estética retro pixel-art. 

##  Tecnologías Utilizadas
* **Backend:** Python (Framework Flask)
* **Frontend:** HTML5, CSS3 (Animaciones y diseño UI/UX)
* **Lógica y Renderizado:** JavaScript (HTML5 Canvas API)
* **Almacenamiento:** LocalStorage (Sistema de logros guardados en el navegador)

##  Características Principales
* **Exploración Libre:** Movimiento fluido por un mapa a gran escala con sistema de colisiones y límites de cámara.
* **Fichas Interactivas:** Interfaz de usuario dinámica que muestra información detallada, estadísticas y áreas de estudio de cada facultad al presionar la tecla `E`.
* **Sistema de Logros:** Rastreo de exploración mediante memoria local del navegador, recompensando al usuario por descubrir nuevas zonas.
* **Inmersión Sonora:** Sistema de audio dinámico y controlable para música ambiental en el menú y durante la exploración del mapa.

##  Instrucciones de Ejecución Local
Para correr este proyecto en tu propia máquina:
1. Asegúrate de tener **Python** instalado.
2. Clona este repositorio y abre la carpeta del proyecto.
3. Instala Flask si no lo tienes: `pip install flask`.
4. Ejecuta el archivo `JUGAR_UCE.bat` (en Windows) o directamente en consola con `python app.py`.
5. Abre tu navegador y dirígete a `http://localhost:5000/`.
